# SynapseOS

SynapseOS turns an old Android phone (first target: Cloud Mobile Stratus C8) into a smart-home remote,
sensor node and voice satellite for Home Assistant.

**This branch (`claude/research-report`) only holds two notes.** The app, OS tooling, docs and full README
live on the [`main`](https://github.com/AceWood619/synapseos/tree/main) branch.

| File | What it is |
|---|---|
| `SYNAPSEOS_RESEARCH_REPORT.md` | Research report (2026-10-07) on audio, DSU storage, on-device wake word, Android voice-satellite and kiosk options for the phone |
| `coord/2026-10-17-vm64-kids-camera.md` | Coordination note: the repurposed baby-monitor camera's Home Assistant entities, for binding in the Synapse remote |
